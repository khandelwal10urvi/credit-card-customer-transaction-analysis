 Credit Card Customer Transaction Analysis

An interactive Power BI dashboard developed to analyze credit card transaction performance and customer characteristics across financial, demographic, and transaction-related dimensions.

 Problem Statement:
 To transform and analyze credit card transaction and customer data to provide a consolidated view of financial performance and customer segments through interactive business intelligence reporting.

 Objective:

To develop an interactive dashboard for analyzing transaction performance, customer demographics, card categories, transaction channels, and key financial KPIs.

 Tech Stack :

Power BI | Power Query | SQL | Microsoft Excel

 Dashboard:

The dashboard consists of two analytical views:

Transaction Report — Analyzes transaction activity and financial performance.

Customer Report — Analyzes customer demographics and segmentation.

 Key Metrics -

656K+ Transactions** | ₹55M+ Revenue| ₹7.84M+ Total Interest | ₹45M+ Transaction Amount | ₹576M+ Total Income
